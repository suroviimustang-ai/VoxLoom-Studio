# Загрузка и установка

[English](DOWNLOADS.md) | **Русский**

Откройте [GitHub Releases](https://github.com/suroviimustang-ai/VoxLoom-Studio/releases)
и разверните список **Assets** нужного выпуска. Интерфейс приложения сейчас русский;
ссылки выбора языка в репозитории переключают документацию.

| Система | Файл | Установка и запуск |
| --- | --- | --- |
| Windows 10/11 x64 | `VoxLoom-Studio-0.3.0-windows-x64.exe` | Запустите установщик для текущего пользователя |
| Ubuntu 24.04 x64 | `VoxLoom-Studio-0.3.0-linux-x86_64.AppImage` | Разрешите выполнение файла и запустите его |
| macOS 15+ Apple Silicon | `VoxLoom-Studio-0.3.0-macos-arm64.dmg` | Откройте образ и перетащите VoxLoom в Applications |

Первый бинарный выпуск имеет статус preview. EXE не подписан сертификатом;
macOS-приложение не имеет Developer ID и notarization. Проверенные ОС и коммит
указаны в отчётах выпуска. Intel Mac этим профилем зависимостей не поддерживается.

На Linux:

```bash
chmod +x VoxLoom-Studio-0.3.0-linux-x86_64.AppImage
./VoxLoom-Studio-0.3.0-linux-x86_64.AppImage
```

Если в системе нет FUSE:

```bash
APPIMAGE_EXTRACT_AND_RUN=1 ./VoxLoom-Studio-0.3.0-linux-x86_64.AppImage
```

## Дополнительные пакеты моделей

В компактном приложении сразу доступны Spectral Gate, DSP, RNNoise и Silero VAD.
Из **того же выпуска** скачайте только нужные дополнительные ZIP-пакеты:

| Пакет | Назначение | Размер распакованной модели, примерно |
| --- | --- | --- |
| `VoxLoom-Models-whisper-base-v1.zip` | Быстрый черновик расшифровки | 148 МБ |
| `VoxLoom-Models-whisper-small-v1.zip` | Сбалансированное распознавание, модель по умолчанию | 486 МБ |
| `VoxLoom-Models-whisper-large-v3-turbo-v1.zip` | Более крупная модель распознавания | 1,62 ГБ |
| `VoxLoom-Models-DeepFilterNet3-v1.zip` | Нейросетевая очистка речи | 9 МБ |
| `VoxLoom-Models-flexsed-v1.zip` | Поиск звуковых событий FlexSED + CLAP | 937 МБ |

1. Не распаковывайте ZIP вручную.
2. В VoxLoom откройте **Модели → Установить пакет…**.
3. Выберите один или несколько пакетов. Перед активацией приложение сверит состав,
   размеры и SHA-256 файлов со встроенным каталогом.
4. Дождитесь сообщения об установке. На вкладке **Речь** выберите установленную
   модель распознавания. Перезапуск и интернет после установки не требуются.

При ошибке или отмене незавершённая модель не становится активной. При замене
предыдущая ревизия остаётся на диске. Учитывайте место под скачанный ZIP,
распакованную модель и старые ревизии.

Модели хранятся отдельно от приложения:

- Windows: `%LOCALAPPDATA%/VoxLoom/models`.
- macOS: `~/Library/Application Support/VoxLoom/models`.
- Linux: `${XDG_DATA_HOME:-~/.local/share}/voxloom/models`.

Для другого расположения задайте `VOXLOOM_MODEL_HOME` с абсолютным путём перед
запуском. Не редактируйте указатели ревизий `current.json` вручную. Новые версии
приложения могут иметь другой каталог сумм — используйте совместимые пакеты.

## Проверка загрузок

В выпуске есть `SHA256SUMS.txt` и отчёты сборок. Например, в Windows:

```powershell
Get-FileHash -Algorithm SHA256 .\VoxLoom-Studio-0.3.0-windows-x64.exe
```

Сравните результат со строкой нужного файла в `SHA256SUMS.txt`. На Linux используется
`sha256sum`, на macOS — `shasum -a 256`. Содержимое моделей дополнительно проверяется
при установке. Целостность файлов не доказывает точность распознавания: текст нужно
сверять прослушиванием.
