# Загрузка и установка

[English](DOWNLOADS.md) | **Русский**

Эта инструкция относится к **VoxLoom 0.3.0**. Для обычной установки не нужны
Python, Git, терминал Windows, API-ключи или отдельная видеокарта. Интерфейс
приложения русский; ссылки выбора языка переключают документацию.

## 1. Скачайте приложение для своей системы

Используйте прямую ссылку в таблице. Эти же файлы есть в разделе **Assets**
[выпуска 0.3.0](https://github.com/suroviimustang-ai/VoxLoom-Studio/releases/tag/v0.3.0).
Архивы **Source code** и файлы отчётов `.json` для установки не нужны.

| Система | Файл | Установка и запуск |
| --- | --- | --- |

| macOS 15+ Apple Silicon | [Скачать DMG · 289 МБ](https://github.com/suroviimustang-ai/VoxLoom-Studio/releases/download/v0.3.0/VoxLoom-Studio-0.3.0-macos-arm64.dmg) | Откройте образ, перетащите VoxLoom в Applications («Программы») и запускайте оттуда |

Первый бинарный выпуск имеет статус preview. EXE не подписан сертификатом;
macOS-приложение не имеет Developer ID и notarization. Проверенные ОС и коммит
указаны в отчётах выпуска. Intel Mac этим профилем зависимостей не поддерживается.

На Linux:

```bash
chmod +x VoxLoom-Studio-0.3.0-linux-x86_64.AppImage
./VoxLoom-Studio-0.3.0-linux-x86_64.AppImage
```

Если в системе нет FUSE:

```bash
APPIMAGE_EXTRACT_AND_RUN=1 ./VoxLoom-Studio-0.3.0-linux-x86_64.AppImage
```

## 2. Выберите модели

**Для первого запуска достаточно Whisper Small.** Он превращает речь, в том числе
русскую, в текст и уже выбран в приложении по умолчанию. При желании добавьте
DeepFilterNet3 для нейросетевой очистки. Остальные пакеты можно установить позже.

В версии 0.3.0 нет встроенного скачивания моделей: откройте ссылку ниже в браузере,
сохраните ZIP, затем импортируйте его в приложение. Одни и те же пакеты подходят
для Windows, macOS и Linux.

В компактном приложении сразу доступны Spectral Gate, DSP, RNNoise и Silero VAD.
Из **того же выпуска** скачайте только нужные дополнительные ZIP-пакеты:

## 3. Установите скачанные пакеты

1. Не распаковывайте ZIP вручную.
2. В VoxLoom откройте **Модели → Установить пакет…**.
3. Выберите один или несколько пакетов. Перед активацией приложение сверит состав,
   размеры и SHA-256 файлов со встроенным каталогом.
4. Дождитесь сообщения об установке. На вкладке **Речь** выберите установленную
   модель распознавания. Перезапуск и интернет после установки не требуются.
5. Откройте **Модели** ещё раз: для стартового набора должно появиться
   **Whisper small: готова**, а при установке очистки — **DeepFilterNet3: установлена**.
   Остальные модели могут оставаться неустановленными.

## 4. Получите первый текст

1. Откройте короткую запись с понятной речью через **Ctrl+O** или перетащите её в окно.
2. Оставьте активной исходную дорожку **A**. Перейдите на вкладку **Речь** и нажмите
   **Найти речь на дорожке**. На дорожке должны появиться цветные интервалы.
3. Щёлкните один интервал или выделите небольшой участок мышью. Выберите модель
   **small** и язык **Русский** для русской записи, затем **Распознать выделение**.
4. Дождитесь текста, сверьте его прослушиванием и сохраните кнопкой **TXT**.

Очистка перед распознаванием необязательна. Для сравнения откройте вкладку
**Очистка**, выберите RNNoise или установленный DeepFilterNet3 и выполните обработку.
Исходник остаётся на **A**, результат — на **B**. Сравните их прослушиванием;
для распознавания обработанного звука выберите **B**.

## Если что-то не получилось

| Что видно | Что сделать |
| --- | --- |
| Модель не установлена | Импортируйте нужный ZIP через «Модели». Затем на вкладке «Речь» выберите именно установленную модель: Base не заменяет Small автоматически |
| Кнопка распознавания недоступна | Сначала откройте аудио и выделите речевой интервал или участок мышью; дождитесь завершения другой обработки |
| ZIP не принимается или не совпала контрольная сумма | Скачайте пакет заново из выпуска 0.3.0. Используйте исходный ZIP без ручной распаковки; архив исходников приложения не является пакетом модели |
| Не хватает места | Освободите место для приложения, скачанного ZIP и распакованной модели; размеры моделей указаны выше |
| Обработка слишком долгая или не хватает памяти | Начните с короткого выделения; установите Base и выберите `base` вместо более крупной модели |
| Операционная система блокирует запуск | У этой preview-версии нет подписи Windows и нотарификации Apple. См. [пояснение Microsoft](https://support.microsoft.com/en-gb/windows/security/windows-security/app-browser-control-in-the-windows-security-app) или [Apple](https://support.apple.com/en-us/102445). Инструкция не требует отключать защиту системы |

Если проблему решить не удалось, [создайте обращение](https://github.com/suroviimustang-ai/VoxLoom-Studio/issues)
с версией ОС и приложения, выбранной моделью и точным текстом ошибки.
Для обращения обычно достаточно описания; личные записи и расшифровки прикладывать не нужно.

## Хранение моделей и обновление

При ошибке или отмене незавершённая модель не становится активной. При замене
предыдущая ревизия остаётся на диске. Учитывайте место под скачанный ZIP,
распакованную модель и старые ревизии.

Модели хранятся отдельно от приложения:

- Windows: `%LOCALAPPDATA%/VoxLoom/models`.
- macOS: `~/Library/Application Support/VoxLoom/models`.
- Linux: `${XDG_DATA_HOME:-~/.local/share}/voxloom/models`.

Для другого расположения задайте `VOXLOOM_MODEL_HOME` с абсолютным путём перед
запуском. Не редактируйте указатели ревизий `current.json` вручную. Новые версии
приложения могут иметь другой каталог сумм — используйте совместимые пакеты.

## Проверка загрузок

В выпуске есть `SHA256SUMS.txt` и отчёты сборок. Например, в Windows:

```powershell
Get-FileHash -Algorithm SHA256 .\VoxLoom-Studio-0.3.0-windows-x64.exe
```

Сравните результат со строкой нужного файла в `SHA256SUMS.txt`. На Linux используется
`sha256sum`, на macOS — `shasum -a 256`. Содержимое моделей дополнительно проверяется
при установке. Целостность файлов не доказывает точность распознавания: текст нужно
сверять прослушиванием.
